# Preston N. Yealy Engineering Portfolio

Static engineering portfolio focused on systems integration, test engineering, verification and validation, automation, embedded systems, and defense technology.

## Files

- `index.html`: complete portfolio website
- `assets/Preston_Yealy_Resume.docx`: downloadable resume
- `START_HERE.md`: beginner Git and GitHub walkthrough
- `projects/PROJECT_CASE_STUDY_TEMPLATE.md`: reusable documentation framework

## Before publishing

1. Replace every instance of `YOUR_USERNAME` with your GitHub username.
2. Confirm the contact information and wording.
3. Add project photographs when available.
4. Never publish proprietary EnerSys data, drawings, customer information, or internal documentation.
