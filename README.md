# Preston N. Yealy Engineering Portfolio

Static engineering portfolio focused on systems integration, test engineering, verification and validation, automation, embedded systems, and defense technology.

## Files

- `index.html`: homepage structure and content
- `styles.css`: shared visual system and responsive layouts
- `script.js`: mobile navigation and automatic footer dates
- `projects/trebuchet.html`: first engineering case study
- `assets/projects/trebuchet/`: portfolio-safe SolidWorks visuals
- `assets/Preston_Yealy_Resume.docx`: downloadable resume
- `START_HERE.md`: beginner Git and GitHub walkthrough
- `projects/PROJECT_CASE_STUDY_TEMPLATE.md`: reusable documentation framework

## Before publishing

1. Confirm the contact information and wording.
2. Add project photographs when available.
3. Never publish proprietary EnerSys data, drawings, customer information, or internal documentation.
