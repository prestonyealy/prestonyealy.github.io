# Preston N. Yealy Engineering Portfolio

Static mechanical engineering portfolio focused on systems integration, test engineering, verification and validation, automation, mechatronics, thermal systems, and engineering software.

## Files

- `index.html`: homepage structure and content
- `styles.css`: shared visual system and responsive layouts
- `script.js`: mobile navigation and automatic footer dates
- `projects/trebuchet.html`: SolidWorks trebuchet design
- `projects/rocky.html`: educational robot and test-lead case study
- `projects/computational-methods.html`: MATLAB fluids and heat-transfer analysis
- `projects/ideal-gas-interpolator.html`: MATLAB App Designer property tool
- `projects/combined-cycle.html`: collaborative thermal-system and cost model
- `projects/food-chopper.html`: multi-link mechanism and validation-gap case study
- `projects/rc-transient.html`: Arduino RC transient data acquisition
- `assets/projects/`: portfolio-safe visuals extracted from Preston's own submissions
- `assets/Preston_Yealy_Resume.docx`: downloadable resume
- `START_HERE.md`: beginner Git and GitHub walkthrough
- `projects/PROJECT_CASE_STUDY_TEMPLATE.md`: reusable documentation framework
