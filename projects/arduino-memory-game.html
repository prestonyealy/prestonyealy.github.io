System loop

Hardware and software had to agree on every input.

The circuit combined LEDs, push buttons, a piezo buzzer, and calculated current-limiting resistors. Firmware converted that hardware into a playable state machine.

Idle→Generate sequence→Playback→Read player→Compare→Feedback
Signal integrity

Debounce the buttons

One physical press can create several rapid electrical transitions. Input debouncing prevents those transitions from becoming false moves.

Program structure

Use finite states

Explicit game states separate sequence playback, player entry, comparison, success, and reset behavior.

User feedback

Map light to sound

Frequency-mapped audio reinforces each LED channel and makes success or failure immediately legible.

A strong system description; a thin visual record.
